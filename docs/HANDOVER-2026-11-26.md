## Pitfalls that cost hours
- `/root/unixnu-work` is on the **NTFS hard disk via FUSE**: tiny-file work crawls (the kernel tree compare, Data template copy). Keep build trees on the SSD (`/`, ~98 GB free; `ufs-variant-macos` is only 1.4 GB).
- `unixnu build kernel` can return 0 after a failed link: `build-macos-ramroot.sh` now refuses a stale kernel.
- Kernel command line ≤1000 bytes; prelink `__TEXT` hole is tight (big const data → `__DATA`).
- Hard reset to **Android** (not fastboot) = reset from below XNU (TZ/hypervisor/PMIC), not a panic. Panics land in fastboot (reboot cell marked). Recover with `adb reboot bootloader`.
- Random early resets at `zap scm init_image` = SPMI traffic during a TrustZone call (buttons/battery threads).
- Don't `pkill -f` patterns that match your own shell; DroidCam frames are often corrupted — trust USB `fullshot`.
