# Status 2026-11-26: first macOS desktop

macOS 27.3 (`26C5035r`) on the Redmi Pad Pro 5G reaches the Finder desktop (Dock, menu bar, wallpaper). All checks below were
made over the USB debug link (`tools/ruan-usbdbg.py`), not with a camera.

## What got the desktop up

| Blocker | Fix | Where |
|---|---|---|
| usermanagerd aborted at the first login (`_gPersonaManager != nil`) | stop publishing `/chosen/ephemeral-storage` (`persistent_data = true`) | `tools/make-macos-ufs-board.sh` |
| SecurityAgent died on `eor3` (FEAT_SHA3), so the login was thrown away | EL0 emulation of EOR3/BCAX/RAX1/XAR, SHA512H/H2/SU0/SU1 and SB (checked against qemu, 20 000 random inputs each) | `unixnu-ruan-macos/patches/xnu-12377/ruan-sha3-emulate.patch` |
| WindowServer alignment faults (`stur q0` into GPU memory mapped Device-nGnRnE) | unmanaged DRAM at or above `ruan-wc-dram` defaults to write-combined | `ruan-wc-dram-unmanaged-default.patch` |
| ~19 min UserAccountUpdater migration every boot before the Dock starts | per-user `loginwindow.plist` build stamps | `tools/make-macos-data.py` |
| coreaudiod / audiomxd spinning on the one CPU (no audio hardware driver), Installer Progress, bluetoothd | disabled in the Data volume | `tools/make-macos-data.py` |
| A stale kernel was packed after a failed link | the build now fails unless the kernel is new | `tools/build-macos-ramroot.sh` |

## Drivers, checked on the tablet

| Feature | Result |
|---|---|
| Touch (Novatek NT36532 over SPI) | multi-finger reports reach `IOHIDEventDriver` (`touch.status`: `hid reports 29, pointer handleReport 29`) |
| Battery | IOPMPowerSource: level and charging state (`battery`: 64-69 %, `ext=1 chg=1`) |
| Backlight | SY7758 over I2C, macOS brightness properties (`backlight`: ready, 0 errors) |
| CPU clock | A55 domain 1804 -> 1958 MHz (`cpufreq`) |
| Display | panel scans exactly the framebuffer (`fb.scan`: `diff64=0`, no underrun); the CPU copy now waits for the GPU fence |

## Open

- **Buttons:** the button driver polls the PMIC arbiter; boots with it on reset early at random (20 s to 5 min). A real SPMI lock
  shared with the battery thread did not fully cure it. Off (`buttons=0`) until understood.
- **GPU hang:** one stable boot logged `coreanimation:Metal … GpuHang` at 676 s and never swapped; suspected CPU starvation from
  1 ms touch polling (`touch_fast=1`) without the touch interrupt. Fast polling only while a finger is down is next.
- **Speed:** one A55 core, ~30 min to the desktop. Staged: boot on an A78 core (est. 3-4x), then SMP.
- **DriverKit cache:** not yet PAC-stripped on `sda22` (a dext dies on `braa`); a stripped cache and trust cache are ready, the
  root image needs a reflash.
- **Rotation:** fixed landscape (`fb-rotate=1|3`) is built in, off by default; real auto-rotate needs the ADSP sensor hub.
